## 2. 当前仍然只是参考目录

商品来源为公开零售目录，不代表 NOVA WELL 已取得供货、经销关系、库存或商业报价。没有复制源店营销段落，也不把来源品牌标成 NOVA WELL 自有品牌。

- 新24款全部显示“Price to be confirmed”，不是 £0、免费商品或直接把美元符号换成英镑。源店零售价格不能代替本站成本和毛利测算。
- 不沿用源店库存状态。所有新款均不可加入演示购物袋或进入结账；未更改原有概念商品的演示袋行为。
- 没有把金色外观写成纯金，也没有默认加入防过敏、防水、UV防护、环保、产地或认证声明。本站采购版本的材质、尺寸和安全资料仍待核实。
- 详情页保留来源和核对日期，未声称品牌合作。实际经营前需确认对应商品和图案／图片的使用权、供应合同及售后责任。
- 部分款式只有一张源图，未生成或冒充不存在的背面和佩戴实拍。

## 3. 核心判断：先把展示目录变成可经营的商品目录

现有页面骨架足以继续填充商品。下一步最大缺口是商品事实、供应与交易闭环；继续堆叠动画和横幅的价值较低。以下顺序为针对本仓库的实施建议。

### P0：先完成，决定能否开放真实销售

| 工作项 | 当前遗漏 | 下一步交付与验收 |
| --- | --- | --- |
| 选品与供货 | 参考店是零售商，不是已确认供应商；城市文字商品偏美国语境 | 确认实际供应商和商品版本，优先确定面向英国／北欧的主售款。保留原产品实际图案，不能只改网页名就把 Chicago 变成 London |
| SKU与变体 | 原店分开的颜色款目前按来源分开展示 | 建立本站主商品ID、颜色／尺寸变体、采购编号、库存来源。只有确认是同款后才合并页面，避免错误合款 |
| 规格与佩戴判断 | 缺少本站确认的尺寸、材质、重量、扣合方式 | 为包挂补尺寸／挂扣；耳饰补单只或成对重量、耳针／耳夹方式；项链补链长／延长链；包袋补容量参照；帽袜补适配范围。填写真实数值，不使用推测数字 |
| 地区价格 | 旧演示价和新商品待定价并存 | 核定成本、币种、地区售价、税费与配送成本，建立可维护的价格表。价格确认前新商品继续不可购买 |
| 客服与履约 | 联系、退换货和物流页面还不是可执行服务 | 确认经营者、客服邮箱／时段、发货地、承运商、费用、可执行退货地址及流程；按目标市场审核政策 |
| 订单与支付 | 无后端库存、订单或支付回调 | 资格确认后接托管结账；服务端校验价格和库存；验签、幂等建单、退款和异常通知。完成真实环境测试再开放下单 |

### P1：数据齐备后，优先提升商品理解与查找效率

1. **补尺寸参照和场景图。** 现有白底产品照有助于辨认图案，但无法判断大小、重量和佩戴效果。每款建议真实主图、细节、手持／佩戴比例、包装四种信息；有几种真实图就展示几种，不强造视角。
2. **建立商品参数组件。** 把材质、尺寸、重量、颜色、护理、包装内容做成统一字段；缺失值用“待确认”，避免每个详情页出现不同写法或空标题。
3. **首饰进一步区分耳饰、项链、手链。** 本轮仅6件首饰，放在一个 Jewellery 子类中最清晰；当实际商品增加后再增加这一级筛选。不要为没有商品的分类制造空页面。
4. **保留筛选返回上下文。** 当前分类、排序和分页可写入地址；从商品页返回列表时，还可继续完善恢复之前筛选、页码、滚动位置和焦点的体验。
5. **增加经核实的颜色／图案筛选。** 本轮没有凭照片自动推断材料。以后从统一商品字段生成筛选，显示已选条件并提供一键清除。缺货条件须来自本站库存。
6. **按用途组织推荐。** 当前优先同类商品。下一步可以由经营者配置包袋＋包挂、发饰＋首饰等搭配；不虚构“经常一起购买”数据。
7. **处理缺货和异常状态。** 需要图片缺失、无搜索结果、无库存、变体不可选、配送不支持、支付失败和订单查不到等明确页面。不可把“没有库存数据”显示成“售罄”。

### P2：提升品牌一致性、市场适配与运营效率

- **品牌定位：** 当前服装、家居、配饰和按摩设备并列。建议确定配饰／生活方式集合店的主轴，再决定设备类目是否继续占据主导航；不要在本次填充中擅自删除旧产品。
- **市场语言：** 默认英式英语适合英国与爱尔兰方向。根据用户后续指令，已删除阿拉伯语并提供英文／简体中文切换；中文便于内容维护和验收，并不等于北欧本地化。根据实际首发国家安排对应语言、尺寸单位、币种和经审核的政策，不仅翻译按钮。
- **本地化图案：** 部分来源图片明确带美国城市文字。可先用通用水果、书本、蝴蝶结等款式验证选品，再开发已实际生产的本地主题款；不能在网页中虚构产地、设计故事或“北欧品牌”身份。
- **正式后台：** 现有 admin-demo 只存本机草稿。需要鉴权CMS、图片管理、商品版本、库存同步、操作审计和备份恢复；这比给本机编辑器加一个登录外观更重要。
- **收藏／最近浏览：** 适合未来款式增多后的比较场景，但优先级低于真实规格、售价、配送和售后。增加前明确本地存储说明和清除方式。
- **搜索索引：** 当前保留 noindex，避免把参考商品误当成可售报价。确认正式品牌内容、域名和商品后，再配置 canonical、语言地区URL、sitemap、真实结构数据及重定向，不默认复制零售店SEO段落。
- **移动端密度：** 本轮已经压缩介绍区，分类直接可见；后续检查真实手机、慢网、长标题、触控尺寸和屏幕阅读器。WebP与延迟加载已实现，但性能仍需在实际网络下测量。
- **可信信息：** 真实经营主体、客服、支付渠道与服务范围应可找到；不提前挂假支付Logo、虚假评分、倒计时、免费配送或未核实的认证徽章。
