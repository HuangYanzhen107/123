# 英文／简体中文界面验收

更新：2026-11-03（北京时间）。按用户要求删除阿拉伯语界面，保留英式英语并新增简体中文切换。本次更新同一个饰品 PR，未合并 main 或更新正式站。

## 本次变更

- 57 个页面的导航、分类、商品名称／介绍、帮助政策说明、搜索、购物袋、市场选项、筛选、分页、提示及图片替代文本支持 EN／中文；品牌名、来源品牌、SKU 和商品图片中的实际文字保留。
- 英文界面显示“中文”切换入口，中文界面显示“English”。页面语言分别为 `en-GB`、`zh-CN`，均为从左至右。
- 语言选择通过已有 `novawell_lang` 在本机跨页面／刷新保留。旧 `ar` 或其他不支持的值回退英文，不影响购物袋和市场。
- 删除活动页面、JS、目录数据和渲染器中的阿拉伯语文案、`data-ar`、RTL 样式与阿拉伯语商品字段。历史文档的旧测试记录保留为历史事实；README、AGENTS 和当前路线图更新为中英文要求。
- `data/zh-CN.json` 维护中文词典，`data/editor-language-aliases.json` 维护旧编辑器文案映射。运行 `python3 scripts/render-store.py` 重新生成页面、目录和 `assets/locales.js`。
- 修复在筛选后重置精选顺序可能被 DOM 顺序影响的问题，以原始目录顺序生成分页；中文名称排序使用中文商品名。

## 用户验收建议

1. 打开 PR 最新预览，点顶部“中文”，检查首页、七个饰品分类及任一商品详情。
2. 搜索“樱桃”，查看中文结果；切回 English，确认文案恢复。
3. 刷新或进入另一页，确认语言保留；手机检查菜单、筛选和分页。
4. 验收本次 PR 后再合并至 main，由现有 Cloudflare Git 集成更新正式站。语言改版不等于开放真实销售；现有待确认价格、禁结算和 noindex 保留。
